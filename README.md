# Oficina STEAM · Treinar uma IA com a webcam

Material da oficina da Semana do Trabalho, na Faculdade Senac. Site estático: HTML, CSS e JavaScript, sem build.

- `index.html`: o menu
- `slides.html`: os slides (setas do teclado para navegar)
- `ficha.html`: a ficha de teste, duas por folha A4
- `downloads/`: os slides e a ficha em PDF

A prática usa o [Teachable Machine](https://teachablemachine.withgoogle.com/train/image), do Google.
